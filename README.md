# Bitcoin Mining Minigame

A real-time visualization experiment that transforms live blockchain data into a skill-based clicker game. Connect directly to the Bitcoin mempool and watch actual, unconfirmed transactions stream into the browser in real time.

## Live demo

[Open the Bitcoin Mining Minigame](https://t-julsgaard.github.io/bitcoin-mining-miningame/)

The source application and generator live in [`Bitcoin_Miner_Minigame`](Bitcoin_Miner_Minigame/).
